# HAM Spotter 1.13.3

About and attribution release.

## Highlights
- new `hamspotter about` command
- new **About HAM Spotter / Über HAM Spotter** management-menu entry
- version, maintainer and copyright information
- explicit GNU GPL v3.0 only attribution
- discreet dashboard footer with project link
- English/German manager translation support retained

## Installation
Download **`hamspotter-installer.sh`**, then:
```bash
chmod +x hamspotter-installer.sh
./hamspotter-installer.sh
```

## Existing installations
The V1.13.3 upgrade preserves `.env` and runtime data.
